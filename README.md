# Big-Mart-Sales-Data-Analysis
Performed Exploratory Data Analysis (EDA) on the BigMart sales dataset to identify key factors influencing product sales across different outlets and product categories. The project focuses on data cleaning, visualization, and insight generation to support business decision-making.
Retail sales data containing product attributes (type, MRP, visibility, fat content) and outlet characteristics (size, location, type, establishment year).
Tools & Technologies
Python
Pandas, NumPy
Matplotlib, Seaborn
Cleaned and preprocessed missing and inconsistent data
Analyzed sales trends across outlets and item categories
Studied the impact of MRP, visibility, and outlet type on sales
Created visualizations to highlight patterns and insights
Item MRP and outlet type significantly influence sales
Medium and large outlets generate higher total sales
Sales performance varies by product category and location
